#  Самолеты в воздушных пространствах стран
Программа, которая собирает данные о самолетах в воздушных пространствах тех стран,
которые вы выберете.

По состоянию на 28.04.2026 проект находится в разработке.

Чтобы получить географические координаты стран, используется API [nominatim.openstreetmap.org](nominatim.openstreetmap.org),
а чтобы получить информацию о самолетах — API [opensky-network.org](opensky-network.org).

Пример ответа от [nominatim.openstreetmap.org](nominatim.openstreetmap.org) можно посмотреть
по [ссылке](#Пример-ответа-от-[nominatim.openstreetmap.org](nominatim.openstreetmap.org)).

В ответе нас интересует параметр `boundingbox` — координаты южной, северной, западной и восточной точки страны.

Осталось только получить информацию о самолетах, в данный момент находящихся на земле
или в воздухе в пространстве выбранной страны.

Пример ответа от [opensky-network.org](opensky-network.org) можно посмотреть
по [ссылке](#Пример-ответа-от-[opensky-network.org](opensky-network.org)).

## Разработка
Основные классы для получения информации от API, для работы с информацией о самолетах,
для записи/чтения файла реализованы в отдельном модуле `utils.py`.

Вспомогательные функции для взаимодействия с пользователем реализованы в модуле `utils.py`.

Модуль `main.py` содержит основную функцию для взаимодействия с пользователем.

По состоянию на 28.04.2026 в проекте реализованы следующие функции и классы:

- **Модуль `utils.py`:**

1. Абстрактный класс для класса получения данных по API.
2. Класс для получения данных по API о координатах страны и самолетах,
находящихся в пределах этих координат:
    - Метод-конструктор;
    - Статический метод проверки на подключение к API;
    - Метод получения данных по API и объединение между собой.
3. Класс для работы с информацией о самолетах:
    - Метод-конструктор;
    - Метод-валидатор проверки на отрицательную скорость полета;
    - Метод-валидатор проверки на отрицательную высоту полета;
    - Метод преобразования набора данных в список объектов;
    - Магический метод проверки на меньшее;
    - Магический метод проверки на большее;
    - Магический метод проверки на равенство объектов;
    - Метод преобразования объекта класса в соответствующем виде для сохранения в файл.
4. Абстрактный класс для класса сохранения данных в файл.
5. Класс для сохранения данных в файл в формате json:
    - Метод-конструктор;
    - Метод загружает данные из JSON-файла;
    - Метод сохраняет данные в JSON-файл;
    - Добавляет информацию о самолёте в файл;
    - Удаляет информацию о самолёте из файла.

- **Модуль `functions.py`:**

1. Функция, фильтрующая самолеты по названиям стран их регистрации.
2. Функция, фильтрующая самолеты по диапазону высот полета.
3. Функция, сортирующая самолеты от большего к меньшему по высоте полета.
4. Функция, возвращающая самолеты, входящие в ТОП-N.

- **Модуль `main.py`:**

1. Функция, выводящая результат поиска самолетов по пользовательским критериям.
2. Главная функция для взаимодействия с пользователем

## Пример ответа от [opensky-network.org](opensky-network.org)
```json
{
    "time": 1766142246,                 // UNIX-время сервера OpenSky (секунды)
    "states": [
        [
            "4b1812",                   // ICAO24 — уникальный идентификатор борта
            "SWR438A ",                 // Callsign — позывной рейса
            "Switzerland",              // Страна регистрации ВС
            1766166618,                 // time_position — время последнего обновления позиции
            1766166618,                 // last_contact — время последнего контакта
            -0.0168,                    // longitude — долгота (°)
            51.0888,                    // latitude — широта (°)
            4267.2,                     // baro_altitude — барометрическая высота (м)
            false,                      // on_ground — находится ли самолёт на земле
            189.7,                      // velocity — горизонтальная скорость (м/с)
            129.39,                     // true_track — курс (градусы)
            14.63,                      // vertical_rate — вертикальная скорость (м/с)
            null,                       // sensors — ID сенсоров (null = неизвестно)
            4282.44,                    // geo_altitude — геометрическая высота (м)
            "2061",                     // squawk — код ответчика (транспондера)
            false,                      // spi — специальный сигнал (emergency/priority)
            0                           // position_source — источник позиции
        ],
        ...
    ]
}
```

## Тестирование
Проект использует библиотеку `pytest` для тестирования.
Все основные модули проекта покрыты тестами, что позволяет обеспечивать стабильность
и надежность кода. Тесты находятся в папке `tests`, и их можно запустить командой:
```commandline
 pytest --cov=src --cov-report=html
 ```

### Покрытие тестами
- Покрытие тестами составляет 79%.
- Основные модули, такие как `utils` и `functions` имеют высокий уровень покрытия,
подтверждающий корректность их работы.
- Отчет о покрытии можно найти в папке `htmlcov`, открыв файл `index.html` в браузере.

### Подробности
- Тесты включают проверку всех критических функций.
- Используются параметризированные тесты для различных сценариев.
- Тестирование с Mock и patch.
